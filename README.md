# Projects

A collection of interactive prototypes. Click a title to open the live version.

- **[Spotify Segments](https://vivdenk7.github.io/projects/spotifysegments/)** - Prototype for a Spotify feature enhancement to save custom song segments as assets
- **[Matchpoint](https://matchpoint-beta.vercel.app/)** - Interactive tennis court board for drawing markers and attaching notes to them
- **[À La Short](https://vivdenk7.github.io/projects/alashort/)** - Concept for YouTube Shorts as a small daily menu instead of an endless feed
- **[Travel Plans](https://vivdenk7.github.io/projects/travelplans/)** - Travel calendar with PTO tracking, trip notes, and availability
- **[Ball Machine Sim](https://vivdenk7.github.io/projects/ballmachine-sim/)** - Simulated control panel for a tennis ball machine, with feed rate and spin settings
- **[WC2026](https://vivdenk7.github.io/projects/WC2026/)** - Family bracket pool for the 2026 World Cup, with a live leaderboard
- **[HSPU](https://vivdenk7.github.io/projects/hspu-progress/)** - Progression tracker working toward a freestanding handstand push-up
- **[Daily Planner](https://vivdenk7.github.io/projects/dailyplanner/)** - Time-block planner for laying out the day from 8 AM to 6 PM
- **[Protein Visualizer](https://vivdenk7.github.io/projects/proteinvisualizer/)** - Shows how much of a given food you'd need to eat to get 10g of protein
