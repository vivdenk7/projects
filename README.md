# Projects

A collection of interactive prototypes. Click a title to open the live version.

- **[Spotify Segments](https://vivdenk7.github.io/projects/spotifysegments/)** - Prototype concept for a Spotify feature to save custom song segments as assets
- **[Matchpoint](https://matchpoint-beta.vercel.app/)** - How I track my tennis game and progress each time I hit
- **[À La Short](https://vivdenk7.github.io/projects/alashort/)** - Prototype concept for YouTube Shorts as a small daily menu instead of an endless feed
- **[Travel Plans](https://vivdenk7.github.io/projects/travelplans/)** - How I plan things with my people
- **[Ball Machine Sim](https://vivdenk7.github.io/projects/ballmachine-sim/)** - Ball machine simulation prototype for my Mom
- **[WC2026](https://vivdenk7.github.io/projects/WC2026/)** - Custom bracket pool for the 2026 World Cup, that I made for my family
- **[HSPU](https://vivdenk7.github.io/projects/hspu-progress/)** - Progression tracker working toward a freestanding handstand push-up
- **[Daily Planner](https://vivdenk7.github.io/projects/dailyplanner/)** - Time-block planner to help me simplify the day when I'm stressed
- **[Protein Visualizer](https://vivdenk7.github.io/projects/proteinvisualizer/)** - Shows how much of a given food is needed for 10g of protein, made for my Celiac Vegetarian Diabetic Dad
